# Быстрый старт: первая передача за десять минут

Фото, которое вы пометили тегом в привычном приложении Immich, появляется в библиотеке другого человека, причём копия проверяется раньше, чем сдвинется ваш оригинал.

![Пометить фото, Immich сообщает immich-handoff, фото попадает в библиотеку получателя](../../images/flow.svg)

**Что понадобится:** Immich 3.2.0 или новее, Docker на машине, где он работает, и около десяти минут. Если хотите сначала попробовать сами, [запустите демо](../../../demo/README.md): одна команда, примеры фото, ваше ничто не затрагивается.

## 1. Запустите приложение

В Linux (на Mac используйте `sed -i ''`):

```
git clone --branch v1.3.1 https://github.com/vfuoglio/immich-handoff.git && cd immich-handoff
cp .env.example .env
sed -i -e "s/^WEBHOOK_SECRET=.*/WEBHOOK_SECRET=$(openssl rand -hex 24)/" -e "s/^HANDOFF_STORE_KEY=.*/HANDOFF_STORE_KEY=$(openssl rand -hex 24)/" .env
docker compose up -d
```

> [!TIP]
> Если сеть вашего Immich называется не `immich_default`, сначала задайте `IMMICH_NETWORK` в `.env`. **Сохраните копию `HANDOFF_STORE_KEY`**: ею шифруются ключи, которые приложение хранит для присоединившихся.

## 2. Войдите и предложите сервис

Откройте `http://<ваш-хост>:8080/` по тому же имени хоста, что и Immich, и войдите своим аккаунтом Immich. Выберите **Предложить свой сервис**, дайте ему название (например, «Отпуск 2026»), выберите тег, которым будут пользоваться отправители (например, `share`), и кто может отправлять. API-ключ никто не создаёт вручную: приложение само создаёт ограниченный ключ в каждом аккаунте в момент присоединения, и его можно удалить в Immich в любой момент.

![Форма предложения сервиса](../../images/offer-form.png)

## 3. Дайте кому-нибудь присоединиться

Поделитесь ссылкой-приглашением или QR-кодом сервиса. Другой человек открывает её, входит своим аккаунтом Immich и присоединяется, сам выбирая, что будет с его оригиналами: **оставить их** и отправить копию или **переместить** в корзину, когда у вашей стороны будет проверенная копия.

![Присоединение к сервису и выбор, что будет с вашими оригиналами](../../images/join-choice.png)

> [!WARNING]
> Пока пробуете, выбирайте **оставить**. **Переместить** кладёт оригинал в корзину отправителя после проверки копии.

## 4. Пометьте фото

В приложении Immich добавьте фото тег `share`. Через несколько секунд оно в библиотеке получателя с тегом `inbox`, а страница показывает его в пути. Если не пришло, выполните `docker compose exec immich-handoff /immich-handoff doctor`; он скажет, что не так и как исправить.

![Фото так, как они приходят в Immich получателя](../../images/immich-family.png)

> [!IMPORTANT]
> Всем участникам нужны включённые **теги** в Immich (Настройки аккаунта, Функции, Теги), а затем нужно перезагрузить страницу Immich. Страница замечает это и предлагает кнопку **Включить теги**.
